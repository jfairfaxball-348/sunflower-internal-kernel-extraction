# Bounded session protocol

At start, reconcile live commits, open PRs and Actions in both repositories; read current authority and verify uniqueness. Archive exact incoming text under `sessions/<id>/INPUT.md` and hash it before changing the handoff. Record any owner steering separately.

Freeze one mathematical obligation. Any computation beyond the committed semantic fixtures requires a separate immutable experiment specification before execution: finite population, labels, symmetries, deduplication, runtime/memory cap, seed if relevant, controls, certificates and stop rule. Negative outcomes remain recorded.

Maintain target, claims, source/novelty records, decisions, experiment history, formalisation and publication status. Do not advance a status from evidence for another dimension. Every fifth substantive child session has a progress/correction audit, every tenth a strategy audit.

Close locally with `python3 scripts/validate.py` and `python3 -m unittest discover -s tests -v`. Publish a branch and PR. Inspect actual required check runs, workflow jobs and reviewed head SHA. Merge only with green required checks and existing authority. Verify merge result, remote main and its hosted run. Record checkpoint receipts explicitly; a commit cannot embed its own hash.

The next handoff must include repository identities, reading order, current mathematics, exact target, one bounded objective, constraints, checks and stop rule. Stop without executing it. Parent registration is independently validated and must point to an actual child commit and actual successful CI. Metadata synchronisation does not execute a parent research session.
