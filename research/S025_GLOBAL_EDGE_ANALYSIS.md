## 1. Frozen goal and exact bookkeeping

For each m>=3 and every arbitrary edge-disjoint packing of t complete original m-triple sunflower blocks, select individual edges in H, with |H|>=t/(512m²). Branch A is a globally v-containing H: EMPTY absent and every realised 2-core has codegree >=m, every realised singleton has TRUE m-matching in its FINAL residual graph. Branch B has at least one disjoint selected pair, hence EMPTY realised and TRUE m-triple matching, together with all exact 2-point codegrees and singleton residual matchings. No source-F witness substitutes for selected-H. This frozen dichotomy is stronger than the S024 inequality (a pairwise-intersecting valid H with no common vertex would not be automatically covered). We DO NOT prove or refute the global dichotomy or S024 inequality.

A proposed bookkeeping partition t=t_A+t_B with A >=t_A/(256m²) and B >=t_B/(256m²) would suffice: max(t_A,t_B)>=t/2. **FIRST UNPROVED QUANTIFIED STEP:** there is no universal definition or proof of the two structural masses which assigns EVERY original block, controls repeated LIGHT labels and simultaneous hub/core collisions, and yields *both* final-H certificate-preserving bounds with the frozen constants. In particular the earlier PRIVATE-light and NO-original-heavy results cover significant regimes but not arbitrary original-Q>0 and nonprivate light. Taking an arbitrary split or summing independently certified A and B outputs is not a proof. No extra uncharged O(m²) filtering can be applied.

## 2. Two exact previously established restricted consequences — correction to S024 budget interpretation

**(i) Private-light <=2 original Q supports.** S021 gives WHOLE-block |J|>=t/[126(m-1)^3]. Its valid H=union_(i in J)B_i has exactly m|J| edges, so

    |H| >= m*t/[126(m-1)^3] >= t/(126*m²) > t/(512*m²).

For m>=3 the first >= uses (m-1)^3<=m^3. This ALREADY meets the S024 **individual-edge quantitative bound** in that restricted original-Q, block-private-light population; it does NOT prove that H satisfies the *extra branch A-or-B topology* of frozen S025. S021 itself asserts true final 2/1/EMPTY witnesses on one selected H, not merely external links.

**(ii) Original Q empty (nonprivate light permitted).** S022 gives whole J >=t/[m(3m(m-1)+1)] for block support load <=m. Again m|J|>=t/[3m(m-1)+1]>=t/(3m²)>t/(512m²) for m>=3. Thus this other restricted population also satisfies **S024** with actual internally witnessed all-2/1/EMPTY H. No claim it has necessarily A-or-B topology.

**(iii) Genuine unresolved region.** When ORIGINAL Q is nonempty AND original light vertices are reused across different block supports, even <=2-original-Q blocks have only the inherited whole-block fallback J>=t/[126(m-1)^3(3m(m-1)+1)], hence

    |H| >= m*t/[126(m-1)^3(3m(m-1)+1)] >= t/(378*m^4).

The last is the correct conservative m^-4 individual-edge lower bound; two powers of m remain relative to t/(512m²). Comparing m^-4 with m^-2 as a uniform-m theorem cannot be repaired by changing a numerical constant. Moreover the general frozen packing has no <=2-original-Q assumption at all. The S023 nonprivate-Q nested plane **refutes whole-block** BSEL but DOES have a dense partial selection; there is no counterexample to the global direct target.

## 3. New elementary restricted structural certificates (symbolic)

**CLEAN-STAR transversal lemma.** Suppose t>=1 original blocks ALL have distinct 2-cores {v,x_i}, with x_i pairwise distinct and each block's m third vertices in a common set Z disjoint from {v,x_1,...,x_t}. Assume each z in Z belongs as a possible third vertex to at most m of the t blocks. Then there is an internally m-valid H of >=min(t,m) individual edges with all edges through v; in fact when t>=m, choose exactly ONE edge from EACH of the t blocks, so |H|=t and A holds. Proof: form bipartite incidence i--z, each left degree m and each right degree <=m. For every S of left indices, m|S| incidences enter N(S), which has capacity <=m|N(S)|, so |N(S)|>=|S|. Hall gives distinct z_i. H={{v,x_i,z_i}}. For i!=j, x_i distinct, all z_i distinct and Z disjoint from the x-set: exact intersection {v} only. For t>=m, the residual pairs {x_i,z_i} are disjoint, so nu(H({v}))=t>=m; 2-pairs and EMPTY are UNREALISED. For 1<=t<m retain instead ONE complete original block of m triples: its only realised exact pair kernel is {v,x_i}, witnessed by its m petals; this has |H|=m, A topology. Either yields >=t/(512m²) in the CLEAN-STAR case. **Limit:** arbitrary nonprivate families need not have distinct/private core x_i or bounded third-symbol incidence relative to selected star; an original-Q label can appear among other third symbols. This proves a genuine restricted A case only, not the mass-covering dichotomy.

**GRAPH-REPRESENTATIVE certificate.** Given any simple graph G and a complete m-petal 2-core block B_{uv}={{u,v,z_{uv,j}}:j=1,...,m} per graph edge, where all z symbols are globally distinct AND disjoint from the graph vertex set V(G), take one triple per selected graph edge S. If every vertex of positive S-degree has degree 1 or >=m, and either S has no pair of disjoint graph edges (then EMPTY absent) or the graph (V,S) has matching number >=m, the representatives H are internally m-valid. Proof: distinct representative triples have no exact 2-point intersection (simple graph, private z). A realised singleton {u} arises only for degree>=2; by assumed degree gap this is >=m, and distinct private-neighbour link pairs give an actual matching. EMPTY is realised iff S has disjoint graph edges; by assumption a graph m-matching then gives m disjoint representatives in H. Thus when S=E(G) has min nonzero degree>=m and nu(G)>=m, **all** t single-petal representatives satisfy B, including general graphs beyond S024's K_N. This is a criterion, NOT an arbitrary-graph density extraction theorem: peeling/keeping S can reduce mass and arbitrary nonprivate spokes violate private-z hypothesis.

**Disjoint empty-core control against an overnarrow two-hub classification.** For any m>=3 and integer r>=m, take r original completely disjoint EMPTY-core m-sunflower blocks, all rm triples disjoint. Original Q is EMPTY, no packed block has a heavy-heavy 2-core, and there is no common vertex among triples from different blocks. Any assertion that all t=r original mass must be partitioned ONLY into clean 2-core stars and private heavy-heavy graph edges is FALSE: neither structural class contains any of these r original blocks. Nevertheless H=F itself has |H|=rm, every pair intersection is exact EMPTY, and m disjoint triples witness EMPTY; thus H satisfies B and is a very dense **positive** alternate. It refutes only this overly narrow **coverage step**, NOT GLOBAL_EDGE_DICHOTOMY_512, direct-edge extraction, R3 or TIK. The original-Q-empty bound already covers this source type. In particular a valid global proof must admit empty/singleton original cores and repeated-light behaviour, not assign them to a nonexistent heavy-pair graph.
